## 🚀 Active Portfolio Projects

### [🛡️ API Guard](https://github.com/ahmedyarub/api_guard)
A cross-domain static analysis tool optimized for Java microservices. API Guard discovers REST endpoints and client calls across decentralized Spring Boot services, structures them into an interactive dependency graph, and extends CodeQL capabilities to detect vulnerabilities spanning distributed service boundaries.
*   **Technologies:** C++, Python, Java, WSL, AI Tools

### [🧠 Snap Solve](https://github.com/ahmedyarub/SnapSolve)
A multi-modal personal assistant ecosystem that performs real-time screen capture analysis, listens to ambient conversations, and parses text inputs. Interacts with multiple large language models asynchronously to output instant logic answers and code snippets. Includes a companion Android app.
*   **Technologies:** Python, FastAPI, OCR, Speech-to-Text (STT), Speech Recognition

### [🎙️ Redub](https://github.com/ahmedyarub/redub)
An automated desktop pipeline tool that dynamically replaces native video narration sequences with high-quality, natural-sounding AI neural voices. Recursively sweeps target media directories, handles complex transcription/translation layers, and applies pitch-locked time-stretching algorithms to isolate and prevent overlapping audio artifacts.
*   **Technologies:** Python, LLM Integration, OpenAi Whisper

### [☁️ Cloud Companion](https://github.com/ahmedyarub/cloud_companion)
A proactive desktop interface tool designed to streamline infrastructure error handling. Rather than logging raw configuration errors, it systematically parses local and remote system environments to serve context-aware, deterministic architectural fixes directly within the native workspace view.
*   **Technologies:** C++, Cross-platform, CMake, WSL, API Integration

### [🏥 Epic FHIR Integration](https://github.com/ahmedyarub/epic_demos)
A proof-of-concept pipeline demonstrating secure integration with healthcare information systems. Utilizes the SMART on FHIR authorization standard to safely ingest data from Epic backend registries, featuring decoupled operational modes custom-tailored for patients and healthcare providers.
*   **Technologies:** Python, SMART on FHIR, HL7 FHIR Standards, Epic APIs

### [✈️ Airtickets Laravel Web App](https://github.com/ahmedyarub/airtickets-webapp)
A multi-tier flight inventory web application mapped to backend Python web-scraping agents. Tracks and processes real-time airline ticket valuations purchasable through loyalty points or credit miles, featuring complex RBAC logic for administrators, vendors, and end users to manage sales and commissions.
*   **Technologies:** Laravel, PHP, Python, REST APIs
